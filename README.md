# Log Analyzer

A simple Python program for analyzing login logs.

## Features

* Count successful login attempts
* Count failed login attempts
* Detect users with 3 or more failed login attempts

## Files

* `analyzer.py` — main program
* `log.txt` — sample login log data

## Usage

Run `analyzer.py` with Python 3.

## Future Improvements

- Analyze suspicious IP addresses
